# Adversarial PDF fixtures

Generated by `tools/gen_adversarial_pdfs.py`.

`go test -tags=adversarial` asserts **desired** behavior: a short deadline
cancels quickly with bounded allocation. Failures are real gaps. Unexpected
passes mean the fixture/test missed the path, or the predicted gap was wrong.

| File | Desired behavior |
|------|------------------|
| `many_operators.*.pdf` | Cancel between ops — cheap |
| `flate_bomb_tj.*.pdf` | Short deadline cancels cheaply |
| `huge_literal_tj.*.pdf` | Same |
| `tounicode_cmap.*.pdf` | CMap parse honors caller ctx |
| `predictor_columns.*.pdf` | Cap/reject huge Columns without huge alloc |
| `acroform_fields.*.pdf` | Extraction stays cheap (AcroForm not walked) |
| `nested_content.*.pdf` | Nesting depth error |

```bash
python3 tools/gen_adversarial_pdfs.py -o tools/adversarial_pdfs --scale medium
go test -tags=adversarial -count=1 -v -run Adversarial .
# or: bash tools/run_adversarial_probes.sh
```
